# Конвертер величин на PyQt6

Учебное приложение: перевод длины, массы и температуры, выбор точности и история результатов.

## Запуск

Нужны Python 3 и PyQt6. Из папки `unit_converter` создайте виртуальное окружение и установите зависимости:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python site.py
```

Программа самостоятельно ничего не устанавливает. Поддерживаются десятичные точка и запятая.
Отрицательные длина и масса, температура ниже абсолютного нуля, бесконечность,
NaN и слишком большой результат отклоняются с сообщением.

## Соответствие заданию

1. Главное окно — `QMainWindow`.
2. Текстовые элементы — `QLabel`.
3. Поле ввода — `QLineEdit`.
4. Кнопки — перевод, перестановка единиц и очистка истории.
5. Выбор параметров — категория, единицы и точность.
6. Вывод результата — надпись и история `QListWidget`.
7. Обработка событий — сигналы кнопок, Enter и смены категории.
8. Проверка данных — число, допустимый диапазон и конечность результата.
9. Диалоговые окна — ошибки, информация и подтверждение очистки.
10. Компоновка — `QFormLayout`, `QHBoxLayout` и `QVBoxLayout`.
